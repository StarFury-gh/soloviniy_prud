# Partners API

## Authentication

Для защиты ресурсов используется JWT-токен, который передается в заголовке `Authorization`:

```
Authorization: Bearer <your_jwt_token>
```

## Роли пользователей

| Роль | Описание |
|------|----------|
| `user` | Обычный пользователь |
| `admin` | Администратор (имеет доступ к созданию и удалению партнеров) |

---

## Endpoints

### 1. Get All Partners

**GET** `/partners/`

Краткое описание: Получение списка всех партнеров с пагинацией.

#### Параметры

**Query параметры**:

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `limit` | integer | Нет | Количество записей на странице (по умолчанию: 5) |
| `offset` | integer | Нет | Смещение для пагинации (по умолчанию: 0) |

**Заголовки**:

| Заголовок | Значение |
|-----------|----------|
| `Authorization` | `Bearer <token>` (опционально) |

#### Пример запроса

```
GET /partners/?limit=10&offset=0
```

#### Пример ответа (успех)

```json
{
  "partners": [
    {
      "id": "123e4567-e89b-12d3-a456-426614174000",
      "name": "Компания А",
      "description": "Описание компании А",
      "photos": ["abc123.jpg", "def456.jpg"]
    },
    {
      "id": "123e4567-e89b-12d3-a456-426614174001",
      "name": "Компания Б",
      "description": "Описание компании Б",
      "photos": ["ghi789.jpg"]
    }
  ]
}
```

#### Ошибки

| Код | Причина |
|-----|---------|
| `500 Internal Server Error` | Внутренняя ошибка сервера |

---

### 2. Create Partner (тольк�� администратор)

**POST** `/partners/new`

Краткое описание: Создание нового партнера. Доступно только администраторам.

#### Параметры

**Заголовки**:

| Заголовок | Обязательный | Описание |
|-----------|--------------|----------|
| `Authorization` | Да | JWT-токен в формате `Bearer <token>`, где токен принадлежит пользователю с ролью `admin` |

**Тело запроса (Body)**:

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `name` | string | Да | Название партнера |
| `description` | string | Да | Описание партнера |
| `photos` | array of strings | Да | Список изображений в Base64 |

#### Пример запроса

```json
{
  "name": "Компания В",
  "description": "Описание компании В",
  "photos": [
    "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQE...",
    "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."
  ]
}
```

#### Пример ответа (успех)

```json
{
  "created": {
    "id": "123e4567-e89b-12d3-a456-426614174002",
    "name": "Компания В",
    "description": "Описание компании В",
    "photos": ["xyz789.jpg", "abc456.jpg"]
  }
}
```

#### Ошибки

| Код | Причина |
|-----|---------|
| `400 Bad Request` | Неверный формат изображения (должен начинаться с `data:image`) |
| `403 Forbidden` | Пользователь не является администратором |
| `404 Not Found` | Пользователь не найден (токен содержит несуществующий ID) |
| `500 Internal Server Error` | Внутренняя ошибка сервера |

---

### 3. Delete Partner (только администратор)

**DELETE** `/partners/{partner_id}`

Краткое описание: Удаление партнера. Доступно только администраторам.

#### Параметры

**Путь (Path)**:

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `partner_id` | string (UUID) | Да | Идентификатор партнера |

**Заголовки**:

| Заголовок | Обязательный | Описание |
|-----------|--------------|----------|
| `Authorization` | Да | JWT-токен в формате `Bearer <token>`, где токен принадлежит пользователю с ролью `admin` |

#### Пример запроса

```
DELETE /partners/123e4567-e89b-12d3-a456-426614174000
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.admin_token
```

#### Пример ответа (успех)

```json
{
  "message": "Partner deleted successfully"
}
```

#### Ошибки

| Код | Причина |
|-----|---------|
| `400 Bad Request` | Неверный формат токена |
| `403 Forbidden` | Пользователь не является администратором |
| `404 Not Found` | Партнер с указанным `partner_id` не найден |
| `500 Internal Server Error` | Внутренняя ошибка сервера |

---

### 4. Update Partner (только администратор)

**PATCH** `/partners/{partner_id}`

Краткое описание: Редактирование существующего партнера. Доступно только администраторам.

#### Параметры

**Путь (Path)**:

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `partner_id` | string (UUID) | Да | Идентификатор партнера |

**Заголовки**:

| Заголовок | Обязательный | Описание |
|-----------|--------------|----------|
| `Authorization` | Да | JWT-токен в формате `Bearer <token>`, где токен принадлежит пользователю с ролью `admin` |

**Тело запроса (Body)**:

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `name` | string | Нет | Новое название партнера |
| `description` | string | Нет | Новое описание партнера |
| `photos` | array of strings | Нет | Новый список изображений в Base64 |

> **Примечание**: Хотя бы одно поле должно быть указано для обновления.

#### Пример запроса

```json
{
  "name": "Обновленная Компания В",
  "description": "Обновленное описание компании В"
}
```

#### Пример ответа (успех)

```json
{
  "updated": {
    "id": "123e4567-e89b-12d3-a456-426614174002",
    "name": "Обновленная Компания В",
    "description": "Обновленное описание компании В",
    "photos": ["xyz789.jpg", "abc456.jpg"]
  }
}
```

#### Ошибки

| Код | Причина |
|-----|---------|
| `400 Bad Request` | Неверный формат токена или отсутствие полей для обновления |
| `403 Forbidden` | Пользователь не является администратором |
| `404 Not Found` | Партнер с указанным `partner_id` не найден |
| `500 Internal Server Error` | Внутренняя ошибка сервера |

---

## Описание полей ответов

### Partner Object

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string (UUID) | Уникальный идентификатор партнера |
| `name` | string | Название партнера |
| `description` | string | Описание партнера |
| `photos` | array of strings | Список имен сохраненных изображений |

---

## Пагинация

По умолчанию используется:
- `limit` = 5 (количество записей на странице)
- `offset` = 0 (смещение)

Пример:
```
GET /partners/?limit=10&offset=20
```

---

## Формат изображений

Изображения передаются в формате Base64 с префиксом MIME-типа:

```
data:image/jpeg;base64,/9j/4AAQSkZJRgABAQE...
data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...
```

Поддерживаемые форматы: JPEG, PNG (и другие, определяемые MIME-типом).

---

## Примечания

1. Все ресурсы, кроме `/partners/`, требуют аутентификации администратора.
2. Изображения сохраняются в директорию, указанную в `cfg_obj.UPLOAD_DIR`.
3. При создании партнера изображения сохраняются асинхронно в фоновом режиме.
4. При обновлении партнера достаточно указать только те поля, которые нужно изменить.
5. Удаление партнера также удаляет связанные изображения из базы данных и файловой системы.
